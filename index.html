Instructions

Questions?

Why does Windows SmartScreen block it?

The app isn't code-signed because signing certificates cost $400/year. The project is open source — review the code yourself. Click "More info" → "Run anyway" to bypass SmartScreen.

Is my code safe?

100%. The app has zero network access and collects zero data. It only reads terminal text and sends keyboard input (number + Enter). All code is open source for review.

Will it auto-approve dangerous actions?

No. It only approves prompts with "allow from this project" options. One-time "Yes/No" prompts are untouched. Plus, you control which terminals are monitored.

Can I use this with other AI coding tools?

Currently designed for Claude Code, but the architecture is extensible. Fork the repo and adapt the regex patterns for your tool.

How do I uninstall it?

Close the app from the system tray, then delete the executable. No files are installed elsewhere. No registry entries. Clean removal.

What if I want to contribute?

Pull requests welcome! Check the contributing guide and open an issue to discuss major changes.
