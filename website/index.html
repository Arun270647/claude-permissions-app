FAQ

Is it safe?

Yes. Open source, runs locally, no network access, no data collection. Review the code yourself.

Why does Windows block it?

The app isn't code-signed ($400/year). Click "More info" → "Run anyway" to proceed.

Which terminals work?

Windows: CMD, PowerShell, Windows Terminal. macOS: Terminal.app (iTerm2 coming soon).

Can I customize it?

Yes! Fork the repo, modify the code, build your own version. MIT licensed.
