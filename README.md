# Website Branch

This branch contains the landing page for Claude Permission Assistant.

## 🌐 Live Website

Deployed on Vercel: **[Add URL after deployment]**

## 📁 Structure

```
web/
├── index.html              # Main landing page
├── assets/
│   └── style.css          # Styles
├── vercel.json            # Vercel configuration
└── VERCEL_DEPLOYMENT.md   # Deployment guide
```

## 🚀 Deploying to Vercel

See **[VERCEL_DEPLOYMENT.md](VERCEL_DEPLOYMENT.md)** for complete instructions.

**Quick start:**
1. Go to https://vercel.com/new
2. Import this repository
3. Select `web` branch
4. Deploy!

## 🔄 Automatic Deployments

Every push to this branch automatically triggers a Vercel deployment.

## ✏️ Making Changes

```bash
git checkout web
# Edit index.html or assets/style.css
git add .
git commit -m "Update website"
git push origin web
# Vercel automatically rebuilds!
```
